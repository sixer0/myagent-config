# memory/tasks/ — Task Logs & End-of-Day Reports

## What goes here

- `YYYY-MM-DD-report.md` — end-of-day summary sent to the user
- `YYYY-MM-DD-tasks.md` — intraday task log (optional, for heavy days)

## End-of-Day Report Template

See `_report-template.md` in this folder.

## When to write a report

- At the end of the day (or when the user asks for a summary)
- After any significant session with multiple actions taken
- When the user might forget what happened

## Index is in MEMORY.md

The "End-of-Day Reports" table in MEMORY.md tracks these files.
